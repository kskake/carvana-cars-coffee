# Carvana Cars & Coffee

A car enthusiast website dedicated to Carvana Cars & Coffee events.

## Features
- **Home**: Featured ride from the previous event + next Cars & Coffee details
- **Events**: Upcoming and past dates, locations, and times
- **Gallery**: Photos from recent gatherings

## Tech
Static HTML/CSS/JS site. Open `index.html` in a browser or deploy to GitHub Pages.

## Getting Started
Clone and open `index.html`.

```bash
git clone https://github.com/kskake/carvana-cars-coffee.git
cd carvana-cars-coffee
# Open index.html
```

Built for the car community. All are welcome — bring your ride or just the coffee.
